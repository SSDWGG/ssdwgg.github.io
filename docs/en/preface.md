# Preface

WPD is a personal documentation site built with VitePress.

## What this project focuses on

- documenting practical frontend workflows
- collecting reusable VitePress setup notes
- recording AI tooling, experiments, and project planning

## How to read this site

- Start with `Getting Started` for local development
- Continue with `Configuration` and `Page Config`
- Use `Markdown`, `Components`, and `Plugins` for advanced customization

## Language structure

- Chinese docs live in `docs/zh`
- English docs live in `docs/en`
- The Chinese site runs at `/zh/`
- The English site runs at `/en/`
