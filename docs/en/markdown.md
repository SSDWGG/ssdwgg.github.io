# Markdown

This project extends default Markdown rendering with several VitePress plugins.

## Enabled features

- code line numbers
- table of contents
- task list checkboxes
- Mermaid diagrams
- timeline syntax
- custom fenced block rendering for `md:img`

## Authoring notes

- keep content in standard Markdown when possible
- use VitePress containers and code groups for richer docs
- place shared static assets in `docs/public`

## Locale note

Markdown content is stored separately for:

- `docs/zh`
- `docs/en`
