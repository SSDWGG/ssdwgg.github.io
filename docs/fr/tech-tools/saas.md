# SaaS

SaaS signifie `Software as a Service`. L’utilisateur consomme une application prête à l’emploi sans gérer directement serveurs, déploiement ou maintenance.

## Exemples

- outils de collaboration ;
- CRM ;
- plateformes d’emailing ;
- outils d’analyse ;
- suites bureautiques en ligne.

## Ce que SaaS résout

- démarrage rapide ;
- maintenance externalisée ;
- mises à jour automatiques ;
- accès multi-appareils ;
- coûts plus prévisibles au début.

## Points à vérifier

- modèle de prix ;
- export des données ;
- intégrations ;
- gestion des droits ;
- conformité et localisation des données ;
- dépendance fournisseur.

## Processus d’adoption

1. clarifier le besoin métier ;
2. comparer les produits ;
3. tester avec un périmètre limité ;
4. configurer rôles et sécurité ;
5. documenter l’usage interne.
