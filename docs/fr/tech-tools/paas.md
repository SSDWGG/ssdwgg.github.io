# PaaS

PaaS signifie `Platform as a Service`. La plateforme gère une partie de l’infrastructure pour que l’équipe se concentre davantage sur l’application.

## Exemples

- plateformes d’hébergement d’applications ;
- services managés de build et déploiement ;
- bases de données managées ;
- fonctions serverless ;
- environnements de staging automatiques.

## Ce que PaaS résout

- moins de maintenance serveur ;
- déploiement plus simple ;
- intégration CI/CD plus rapide ;
- montée en charge plus facile ;
- observabilité souvent intégrée.

## Flux typique

1. préparer l’application ;
2. définir variables d’environnement ;
3. connecter le dépôt Git ;
4. configurer build et start command ;
5. publier et surveiller les logs.

## Points de vigilance

- coût à long terme ;
- limites de runtime ;
- vendor lock-in ;
- accès réseau ;
- stratégie de sauvegarde.
