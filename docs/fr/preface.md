# Préface

WPD est un site de documentation personnel construit avec VitePress. Il sert à conserver des notes techniques, des pratiques de développement, des expérimentations autour de l’IA et des pages de projets.

## Objectifs

- garder une base de connaissances lisible et durable ;
- documenter les choix de configuration du site ;
- rendre les contenus importants accessibles en plusieurs langues ;
- relier les pages de référence, les outils et les projets personnels.

## Comment lire le site

- commencez par `Démarrage` pour comprendre le projet ;
- continuez avec `Configuration`, `Pages` et `Frontmatter` pour les bases VitePress ;
- utilisez `Markdown`, `Composants`, `Plugins` et `Mise en page` pour les personnalisations avancées ;
- consultez `IA`, `Développement` et `Outils techniques` pour les notes de travail.

## Structure linguistique

- les documents chinois vivent dans `docs/zh` ;
- les documents anglais vivent dans `docs/en` ;
- les documents français vivent dans `docs/fr` ;
- les chemins publics sont `/zh/`, `/en/` et `/fr/`.
