# Liens permanents

Les liens permanents permettent de garder des URLs stables même si les fichiers ou titres changent.

## Pourquoi c’est utile

- éviter de casser des liens déjà partagés ;
- garder les URLs lisibles ;
- séparer l’organisation interne des fichiers et les chemins publics ;
- faciliter la migration de pages.

## Dans ce projet

La logique liée aux permaliens se trouve dans le thème et la configuration VitePress. Les pages de test montrent comment un chemin peut être maintenu proprement.
