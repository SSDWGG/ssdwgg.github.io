# Style — bordure fluide

Cette page sert d’entrée française pour la démonstration de bordure fluide.

## Objectif

La démonstration montre comment un composant Vue peut enrichir des blocs visuels tout en restant piloté par la documentation.

## À vérifier

- lisibilité en mode sombre ;
- comportement responsive ;
- coût d’animation raisonnable ;
- textes localisés dans `locale.ts` quand ils sont partagés.

## Références

- Version chinoise : `/zh/style-fluidborder`
- Version anglaise : `/en/style-fluidborder`
