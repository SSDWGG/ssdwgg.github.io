# Journal des changements

> [!IMPORTANT] À propos de ces notes
>
> Cette page résume les changements importants du site : contenu, structure, documentation, déploiement et maintenance. Les commits répétitifs de test ou de déploiement sont regroupés.

> [!TIP]
> Version chinoise : `/zh/changelog`  
> Version anglaise : `/en/changelog`

::: timeline 2026-04-25
- Complété la locale française avec des pages de documentation, une sidebar dédiée, des liens de navigation et des entrées pour IA, développement, outils techniques, projets et pages annexes.
- Ajouté la prise en charge française des composants partagés du thème, y compris les textes de recherche, les libellés d’interface et la page d’accueil française.
- Amélioré la page racine du site avec une entrée multilingue au lieu d’une redirection unique.
- Étendu le module chinois `Outils techniques` avec des guides JavaScript asynchrone, SaaS et PaaS.
- Ajouté un script local de déploiement avant commit qui construit VitePress puis synchronise la sortie vers le serveur.
:::

::: timeline 2026-04-24
- Étendu le module chinois `Outils techniques` avec OpenCV, Three.js, Vue2, Vue3 et React.
- Ajouté le module chinois `Outils techniques` avec Docker, Nginx et ECS.
- Réorganisé la documentation en sections localisées et ajouté le jeu de pages anglaises.
- Amélioré les ressources locales et les comportements de repli de plusieurs démonstrations.
- Réécrit les pages de développement bilingues autour des modes de livraison, de l’IA, de Git et de Docker-first.
:::

::: timeline 2026-04-23
- Nettoyé le contenu temporaire du mémo pour préparer une structure plus claire.
:::

::: timeline 2026-04-22
- Complété la documentation IA avec Codex, Claude, OpenClaw, la configuration d’environnement et les notes d’accès Chine.
- Amélioré le README, le mémo et les pages de planification.
:::

::: timeline 2026-03-09 ~ 2026-04-03
- Initialisé et consolidé le site VitePress avec thème personnalisé, pages interactives, recherche, analytics, déploiement et ajustements de style.
:::
