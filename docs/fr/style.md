# Styles

Cette page résume l’approche de personnalisation visuelle du site.

## Où modifier

- thème VitePress : `docs/.vitepress/theme/` ;
- styles globaux : fichiers CSS ou Less du thème ;
- composants visuels : `docs/.vitepress/theme/components/` ;
- démonstrations de style : pages Markdown dédiées.

## Bonnes pratiques

- gardez les variables de couleur centralisées ;
- évitez les styles globaux trop larges ;
- testez les modes clair et sombre ;
- vérifiez les pages de documentation longues, pas seulement la page d’accueil.

## Références

- Version chinoise : `/zh/style`
- Version anglaise : `/en/style`
