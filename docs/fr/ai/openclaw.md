# OpenClaw

OpenClaw est présenté ici comme un outil local d’orchestration et d’accès à des capacités IA.

## Ce que la page couvre

- rôle d’OpenClaw dans un environnement local ;
- relation avec les modèles et fournisseurs ;
- configuration générale ;
- points de vigilance sur les accès et secrets.

## Bonnes pratiques

- gardez la configuration locale hors du dépôt ;
- utilisez les commandes gérées de l’outil pour contrôler les services ;
- documentez les endpoints et fournisseurs réellement utilisés ;
- testez d’abord avec une tâche simple avant de brancher des workflows plus longs.
