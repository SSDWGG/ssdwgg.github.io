# Hermes Agent

Hermes est utilisé comme agent local ou passerelle selon la configuration. Sa valeur principale est de relier modèles, mémoire, outils et tâches automatisées.

## Ce que la page couvre

- rôle général d’Hermes ;
- configuration des fournisseurs ;
- distinction entre protocoles de chat et de réponses ;
- erreurs de routage fréquentes ;
- bonnes pratiques de débogage.

## Points d’attention

- ne mélangez pas les endpoints `chat/completions` et `responses` sans vérifier le mode attendu ;
- gardez les clés et endpoints privés dans les fichiers locaux ;
- réduisez le raisonnement ou la taille de sortie si une réponse est tronquée ;
- changez une seule variable à la fois pendant le diagnostic.
