# Notes d’accès pour la Chine

Cette page résume une approche prudente et conforme pour les services d’IA utilisés depuis la Chine continentale.

## Principe

Il ne faut pas transformer cette documentation en guide de contournement réseau. Le bon objectif est de comprendre la disponibilité officielle, les contraintes de conformité et les alternatives adaptées.

## Recommandations

- vérifiez d’abord les pages officielles du service ;
- évitez de construire une activité critique sur un accès instable ;
- pour un usage d’entreprise, privilégiez les canaux d’achat et de conformité reconnus ;
- documentez les limites de disponibilité pour les utilisateurs concernés ;
- prévoyez des alternatives locales ou des fournisseurs disponibles légalement.

## Alternatives possibles

- modèles locaux pour les tâches sensibles ou hors ligne ;
- fournisseurs officiellement disponibles dans la région cible ;
- workflows hybrides avec contexte minimal et données non sensibles ;
- documentation interne claire sur les outils autorisés.
