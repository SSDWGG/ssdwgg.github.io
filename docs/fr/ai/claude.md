# Claude et Claude Code

Claude est un assistant IA généraliste. Claude Code apporte une expérience plus orientée développement et travail sur dépôt.

## Usages fréquents

- clarification de besoins ;
- explication de code ;
- génération ou réécriture de documentation ;
- analyse d’erreurs ;
- assistance de refactorisation.

## Points de vigilance

- vérifiez les réponses techniques avec les fichiers ou la documentation officielle ;
- ne collez pas de secrets ou données sensibles dans un outil non approuvé ;
- gardez les modifications importantes dans un flux Git traçable.
