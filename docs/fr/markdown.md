# Markdown

VitePress étend Markdown avec des fonctionnalités utiles pour la documentation technique.

## Fonctionnalités activées

- numéros de ligne dans les blocs de code ;
- cases à cocher de type tâche ;
- diagrammes Mermaid ;
- timeline Markdown ;
- icônes de groupes de code ;
- remplacement localisé de certains libellés de conteneurs.

## Exemple de tâche

```md
- [x] Écrire la page
- [ ] Relire les liens
```

## Exemple de bloc de code

```ts
const locale = 'fr'
console.log(`Locale active: ${locale}`)
```

## Bonnes pratiques

- préférez des titres courts et descriptifs ;
- utilisez les tableaux pour comparer des options ;
- gardez les blocs de code exécutables quand c’est possible ;
- reliez les pages voisines avec des liens internes.
