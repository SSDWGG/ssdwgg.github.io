# Synchronisation unidirectionnelle Windows

Cette page sert d’entrée française pour les scripts de synchronisation Windows.

## Objectif

- surveiller un dossier local ;
- synchroniser vers une destination cloud ;
- éviter la synchronisation inverse ;
- garder les logs utiles pour le diagnostic.

## Points d’attention

- testez d’abord sur un dossier temporaire ;
- excluez les fichiers temporaires ;
- vérifiez les droits WebDAV ou cloud ;
- documentez les commandes de démarrage et d’arrêt.
