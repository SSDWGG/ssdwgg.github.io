# Synchronisation unidirectionnelle Mac

Cette page sert d’entrée française pour les scripts de synchronisation macOS.

## Objectif

- surveiller les changements locaux ;
- déclencher une synchronisation unidirectionnelle ;
- garder une trace des erreurs ;
- éviter d’effacer des fichiers distants par accident.

## Points d’attention

- vérifiez la présence de `rclone` et des outils de surveillance ;
- utilisez un dossier de test avant les données réelles ;
- documentez les exclusions ;
- conservez les logs pour le diagnostic.
