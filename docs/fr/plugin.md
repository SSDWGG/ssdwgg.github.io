# Plugins

Le projet utilise plusieurs plugins pour enrichir VitePress.

## Plugins visibles dans la configuration

- `markdown-it-task-checkbox` pour les tâches ;
- `vitepress-plugin-group-icons` pour les icônes de groupes de code ;
- `vitepress-plugin-mermaid` pour les diagrammes ;
- `vitepress-markdown-timeline` pour les journaux chronologiques ;
- recherche locale VitePress.

## Avant d’ajouter un plugin

- vérifiez que le besoin ne peut pas être résolu avec Markdown ou Vue simple ;
- regardez l’impact sur le build et le bundle client ;
- documentez l’usage dans une page dédiée si le plugin devient important ;
- testez avec `pnpm docs:build`.
